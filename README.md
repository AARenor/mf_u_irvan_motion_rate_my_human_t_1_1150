# One-line review

A program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: the single line an agent would post about its human on a rating site. The text is fixed, lives in `main.py` as one string constant, is written to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), and contains no trailing newline.


Run it with:

